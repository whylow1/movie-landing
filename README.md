# КиноМир — лендинг кинотеатра

Одностраничный сайт-афиша фильмов, выполненный в рамках учебного проекта.

**Технологии:** HTML, CSS (Flexbox, Grid, CSS-переменные), JavaScript.

**Функционал:**
- Адаптивный дизайн
- Тёмная/светлая тема (сохраняется в localStorage)
- Динамическая подгрузка карточек фильмов по кнопке «Показать еще»
- Форма обратной связи с валидацией и выводом данных в консоль
- Плавная прокрутка

**Как запустить:** открыть `index.html` в браузере или посетить [живую версию](https://github.com/whylow1/movie-landing.git).
